# Project 4: Prototyping and Development

## Project Context
During this portion of the project you will focus on building and iterating on the solution you have chosen to prototype. You will document your process and choices during this phase of the project and generate a report to share this milestone with the class.

## Instructions

For this milestone deliverable, we would like a 750-word report and will have another workshop style presentation session in class on November 24th. 

### Report Instructions

Your report should include the following:

1. **Prototype Description and Goals**  
2. **List of Technologies/Tools/Materials Used**  
3. **Prototyping and Evaluation Feedback Process**  
    1. We would like to see any documentation of the prototyping process.  
    2. What tools are you using to prototype?   
    3. How have you or how are you going to test your prototypes (how are you getting feedback)?   
    4. If you have already tested what kind of feedback did you receive? Include testing notes, summaries, etc. (Documentation of the testing sessions)  
4. **Prototype Screens/Sketches/Images**  
    1. What does the prototype look like right now? How does it work?  
5. **What’s next?**  
    1. What do you want to finish before the final demonstration?

### Presentation Instructions

During class on November 24th, we will have an informal presentation update from each group and check in on the progress workshop style with the instructors. This will allow each group to share their progress with the class and get feedback or suggestions for any elements of the prototyping/demonstration that could be improved for the final version.

## Deliverables and Deadlines

There are two deliverables for this milestone. 

1. **The report is worth 75 points and is due November 24th by 11:59pm.** The report should be around 750 words. To receive full credit for this milestone, we expect that all sections listed above are included in an accessible document submitted to Canvas.
